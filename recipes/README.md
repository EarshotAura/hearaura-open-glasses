# Recipes

One folder per recipe. Each holds `recipe.json` and anything else that
helps someone build it: photos, drawings, 3D-print files, notes.

`index.json` is generated by `python3 scripts/check.py` from every
`recipe.json` and from `../parts.json`. It is the one file the guide at
https://hearaura.app/build-glasses/ reads. Do not edit it by hand.

To add a recipe, copy `_template` and follow [CONTRIBUTING.md](../CONTRIBUTING.md).
